🎯
문제 정의가 명확한가?
"어떤 사람의 어떤 문제를 해결하는가" — 없으면 첫 페이지에서 탈락
→ 심사 1순위 탈락 요인
⚔️
경쟁사 대비 차별점이 있는가?
"왜 우리 회사여야 하는가" — 없으면 심사위원 설득 불가
→ 가장 많이 탈락하는 항목
📊
시장 규모 수치가 있는가?
TAM/SAM/SOM 또는 통계 출처 — 숫자 없으면 신뢰도 0
→ 수치 없는 계획서는 즉시 감점
👥
팀의 실행력을 증명할 수 있는가?
대표자 이력·팀원 전문성 — 팀이 약하면 아이디어가 좋아도 탈락
→ 심사위원이 가장 중요하게 보는 항목
💰
자금 사용 계획이 구체적인가?
OO에 OO만원 사용 예정 — 뭉뚱그린 계획서는 바로 감점
→ 구체성 없으면 신뢰 불가
